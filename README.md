Kolobok: Escape from the Oven!
2D-платформер на Python (бібліотека pygame-ce), створений для лабораторної роботи
Структура проєкту
1. kolobok_game.py - головний файл запуску гри
2. levels/ - папка з конфігураціями рівнів (tutorial.json, level1.json)
3. best_times.json - збереження найкращих результатів проходження
4. .gitignore - правила ігнорування службових файлів

! Для запуску встановіть бібліотеку pip install pygame-ce
